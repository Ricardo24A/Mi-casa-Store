# Prototipos (solo referencia)

Código exportado de los prototipos aprobados por el cliente. **No forma parte de la app**: está excluido de TypeScript y ESLint y no se despliega.

- `cliente/`: vista del cliente (Figma Make, React + Vite). Incluye también pantallas de admin de una versión anterior.
- El prototipo del dashboard vive en Lovable (enlace guardado por Ricardo).

Sirven para copiar estructura, textos y datos de ejemplo. Donde contradigan el `CLAUDE.md` (pagos, datos de Colombia, promesas comerciales, marca "Nido Hogar"), manda el `CLAUDE.md`.
